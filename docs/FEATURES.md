# saphine 功能与进度

本页记录当前可用能力和已有计划的实现状态。语法示例见 [LANGUAGE.md](LANGUAGE.md)，构建与导入示例见 [README.md](../README.md)。

## 内存管理

- [x] **当前值与引用语义。** 结构体、数组和枚举按值复制。普通指针、切片和实例函数值的引用寿命由程序员负责。ARC、GC 和派生视图按其类型维持对象寿命。 [语言语义](LANGUAGE.md#文件模块与可见性)
- [x] **Zig 内存运行库与 allocator 互操作。** 四种 manager 都能传入 Zig 的 `std.mem.Allocator` 参数。Heap 和 Arena 支持在 saphine 中直接调用 `create(value)`。 [示例](../examples/memory/main.saph)
- [x] **具体 ARC 和 GC 智能指针。** 原生 `create`、自动引用计数、弱引用、GC 根和可保存的派生视图。 [示例](../examples/memory/managed.saph)
- [x] **静态管理接口。** `*Manager` 按 `use` 路径选择标准 manager，支持 `mem.Ptr(T)` 关联返回类型。只读 `Ptr` 支持协变，静态回调支持普通结构体指针和只读 `Ptr` 的逆变，Heap 提供局部重复释放警告。 [示例](../examples/memory/interfaces.saph)

## 已实现

- [x] **绑定与作用域**。`const`、`var`、显式类型标注、类型推断、普通赋值和复合赋值、块作用域与局部遮蔽。标识符支持 Unicode。
- [x] **基本类型与运算**。多位宽整数和浮点数、`bool`、UTF-8 字节串、`void` 和编译期 `type`。支持算术、数值比较、布尔相等和短路逻辑，并检查字面量范围。
- [x] **控制流与集合**。`if`、`while`、`do while`、`for`、`break`、`continue`。支持定长数组、可变和只读切片、下标、区间切片、`.len` 和编译期长度的 `range`。数组按值复制，切片共享底层存储。
- [x] **函数和方法**。显式参数和返回类型、匿名函数、函数值的复制与传递、结构体实例方法及静态成员。支持编译期类型参数和静态特化。
- [x] **结构体与类型演化**。具名字段、默认初始化、取地址、算术、按位、移位、比较和一元运算符重载。支持结构声明展开 `..`、增量扩展、`Self` 版本化和旧实例分发。结构体按值复制。
- [x] **枚举、可空类型与匹配**。支持带或不带载荷的枚举成员、`?T`、构造、穷尽性检查，以及可作为表达式的 `match`。
- [x] **文件模块与组合**。`use` 嵌入实例、提升成员、静态多态及可见性重声明。支持 `public`、`private`、`internal`，路径歧义和循环导入诊断。每条 saphine 文件 `use` 拥有独立实例，初始化按源码顺序执行。
- [x] **标准库**。Saphine 的 `std` 使用 Zig 实现。裸 `print(value)` 通过隐式导入解析，与 `use std: "std";` 后的 `std.print(value)` 共用声明。局部同名绑定优先，运行时提供 IO 上下文。参数迭代和文件读取接受调用方分配器，另有字节搜索和输出接口。 [搜索 CLI](../examples/find/main.saph)
- [x] **Zig 导入与调用**。支持本地 `.zig`、`zig:std` 和显式命名模块。可访问支持类型的公开常量、静态变量及函数，保留可见性和提升歧义检查。同一 Zig 模块的导入共享静态状态。
- [x] **Zig 类型与函数值**。支持显式外部类型的别名、结构体构造和默认字段、字段访问、指针接收者方法、函数值适配器及 ABI 匹配的无捕获回调。支持已解析的 `optional`、`error union` 和具名 error set，以及相应的构造与匹配。
- [x] **工具链与构建**。固定 Zig 0.17.1。提供 `check`、`emit-zig` 和 `build`，支持目标与优化选项。外部可达调用由 Zig 编译验证，交叉检查只编译。
- [x] **可审查的 Zig 输出**。生成格式化 Zig，保留源码名称、具名布局、类型版本及可读签名。无环境需求的函数省略环境参数。生成的 Zig 供审查、定位和构建，维护入口是 saphine 源码及 Zig 库。
- [x] **可搬移产物**。无需额外运行库、外部依赖或显式构建选项的输出可单文件构建。使用内存运行库时随 `.deps` 导出运行库源码。对已支持的外部依赖，导出 Zig 源码、依赖快照、构建命令和源码映射。命名模块可用 CLI 映射或版本化 JSON 配置。

## 部分实现与剩余计划

### Zig 泛型和编译器查询

- [x] 显式 `comptime`、常见 `anytype`、常见类型工厂，查询可处理递归引用并支持交叉目标。
- [ ] 更广的签名和嵌套名义类型、复杂类型的跨模块身份统一、查询所得枚举的匹配。复杂接口可通过显式 Zig 门面接入。

### Zig 类型映射与调用

- [x] 普通指针、切片、部分 sentinel、原始布局及有限回调 ABI。
- [ ] 更多指针限定符和调用约定，以及复杂外部类型的完整操作。

### 构建与依赖封装

- [x] 字面量导入、嵌入资源、逐模块导入映射和显式链接输入。
- [ ] 更完整的条件依赖发现、复杂 C 导入和包外资源封装。当前查询无持久结果缓存。

### 源码映射

- [x] 格式化后映射声明和外部调用，特化声明记录触发点。
- [ ] 局部绑定、更多表达式及完整特化调用链。

### Zig 输出结构

- [x] 按调用图分析环境，已能使用类型化指针。多种环境形状仍走擦除 ABI。
- [ ] native 方法归入所属容器、按需移除布局环境字段，以及更直接的表达式和转换输出。这些是原设计的后续项，可审查输出已可用。

互操作阶段的详细设计与限制见 [ZIG_INTEROP.md](ZIG_INTEROP.md)。

## 已有设计，尚未接入

- [ ] **运行时类型修改与动态后端。** 目前 `type` 在编译期求值，运行时分支无法修改类型绑定。已有设计包括运行时类型描述符、对象快照、动态字段与借用、动态调用 ABI、运行时方法分发，以及内存和生命周期管理。独立运行库实验尚未接入生产编译器。 [动态后端评估](DYNAMIC_BACKEND.md)
- [ ] **更广的闭包捕获。** 当前函数值可保存已有实例环境。任意运行时局部变量捕获及部分跨容器环境仍未实现。 [暂不支持的功能](LANGUAGE.md#暂不支持的功能)

函数局部 `use`、通用生命周期检查、字符串插值也超出当前语言范围。上述 Zig 错误类型支持覆盖互操作场景，通用语言级错误传播仍超出当前范围。
